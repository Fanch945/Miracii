# 积温：主动开口的引擎

一句话：她**想不想找你**由六个连续数值决定——不是骰子，也不需要每拍问一次模型。
规格来源与取舍见 [`reference/jiwen.txt`](reference/jiwen.txt)；实现是 `app/warmth.py`。

## 六个轴

| 轴 | 范围 | 什么时候动 |
|---|---|---|
| **connection** 连接需求 | 0 → 1 | 你多久没说话。前 45 分钟线性（0.0007/分钟），之后按 `(1+c)` 复利加速；**只有它驱动开口** |
| pride 骄傲 | −1 → +1 | 一进"有点想找对方"的带（≥0.35）就开始防御性上升，朝 0.5 漂；平时回归 0 |
| valence 愉悦度 | −1 → +1 | 等待让它缓慢下沉（0.012·c/分钟），你的回话把它拉回来 |
| arousal 唤醒度 | −1 → +1 | 等待让人坐不住（connection ≥0.30 时 0.0075/分钟），到 0.7 触发"找点事做" |
| immersion 沉浸度 | 0 → 1 | 她手上真的有事在消化时才抬起来（见下），高的时候连接需求涨得慢 |
| **hesitation** 犹豫 | 0 → 1 | 只要"还想找你"且"还端着"就一直在咽；到 0.5 给出"欲言又止"的写法提示 |

## 时间线（现行默认、20 分钟一拍、你一直不说话）

| 沉默 | 发生什么 |
|---|---|
| 4 小时 40 分 | `observation`——"偶尔会想起对方"（纯内心，不发消息） |
| **7 小时 20 分** | **`contact`——真的会开口**（仍要过安静时段 / 每日配额 / 正在聊 / 人工 hold / 冷却） |
| 10 小时 | `force_contact`；骄傲爬到 0.5；躁动到 0.7 开始触发"找事做" |
| 11 小时 20 分 | valence ≤ −0.3，真的开始低落 |
| 12 小时 | 犹豫到 0.5，"欲言又止"生效 |
| 16 小时 30 分 | connection 封顶 1.0 |

你回一句话，六轴立刻回落（`reply_delta`：connection −0.25、valence +0.05、arousal −0.15、犹豫 −0.20）。
**等待由"你出现了"解除**，不是她自己开了口就自我安慰。

## 怎么观察她

| 命令 | 看什么 |
|---|---|
| `python -m app.warmth --watch` | **实时一行**：六轴 + 进度条 + 此刻的闸门 + 距下拍到点 + 积压条数（Ctrl+C 退出） |
| `python -m app.warmth --view` | 当前状态 JSON：六轴、**有效门槛**、每道闸门"差多少"、她此刻的内心话与写法提示 |
| `python -m app.warmth --state` | 已落盘的状态 + 距下次到点还有多久 |
| `python -m app.warmth --show` | 当前生效的全部旋钮（含被 `warmth.json` 改过哪些） |
| `python -m app.warmth --review --days 7` | 台账：跨线、被挡、真正开口的话、以及你打的标注 |
| `python -m app.warmth --once --since-message 600` | 干跑一拍，不等到点（会落盘） |
| `python -m app.warmth --mark "这里她该开口" --label should_speak` | 人工标注（校准的唯一输入） |
| `GET http://127.0.0.1:8000/api/warmth?persona=miracii` | 网页侧的同一份数据（只读） |

`--view` 里的 `gates` 就是"她为什么现在不开口"：每条都带 `gap`（还差多少）或 `urgency`（过了多少）。

## 她真的开口要过几道关

积温只回答"想不想"。真正发出去还要过：安静时段、当日配额（`schedule.txt` 的 `quota_speak_per_day`）、
5 分钟内正在聊、人工 hold、以及**两次开口之间的冷却**（`speak_cooldown_minutes`，默认 45 分钟）。

## 文件落在哪

| 文件 | 作用 |
|---|---|
| `persona/<id>/memory/warmth.json` | 人格特化旋钮。**只列值得改的**；删掉即回退默认；坏键坏值只提示不报错 |
| `persona/<id>/memory/warmth-state.json` | 六轴 + 时间戳。删掉即从零开始 |
| `persona/<id>/memory/warmth-log.jsonl` | 台账：`tick`（画像变化）/ `speak`（真的说了）/ `mark`（你的标注） |

三份都是程序自己生成的派生文件，**不碰上面任何记忆与设定文件**，也都在 `.gitignore` 里。

## 还没接通的

- **`user_state`**：接上了（模型从最近对话判断 active/busy/away/sleeping），但只在连接需求逼近开口线、
  且上一次判断过期时才问一次——不是每拍都问。
- **`immersion`**：目前用"学习队列最近两小时内被动过"当"她真的在忙"。**积压是状态不是活动**：
  真实人格队列里积着 18 条但 16 小时没动过，那种情况不计入。
- **`tone-grid`**（9 簇 × 5 档语调网格）与 **`saga` / `circadian` 钩子**还没做。
- **阈值仍未按 Miracii 校准**——需要真实跑几天、你在关键处标 10–20 条。
