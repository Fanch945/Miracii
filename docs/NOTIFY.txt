# 主动开口的桌面提醒：Windows 通知 + 右下角浮动弹窗

她开口的时候，人不一定在窗口前。心跳把那一句写进库之后，顺手在桌面上敲一下：
一条系统通知，加一块右下角的浮层。**窗口在前台时不提醒**——你正看着，页面自己会显示。

## 触发点

只有一处，在 `app/heartbeat.py` 的 `deliver_speak()` 里：

```text
监督 speak=true → 生成那一句 → 写 sqlite / transcripts → notify.proactive()
```

`notify.proactive()` 的返回值（`fired` / `reason` / `toast` / `popup`，出错时带
`toast_error` / `popup_error`）会以 `ping:` 开头写进 `data/heartbeat.log`——**弹没弹都写**，
静默的原因也在里面；提醒自己抛错时写 `notify failed:`，心跳继续。它只跟着**已经决定要说的那一句**
走，不额外制造开口：安静时段、每日 quota、正在聊，仍然由 `_may_speak()` 在更前面挡住。

## 焦点规则

`app/notify.py: window_focused()`。前台窗口满足任一条就算「人在看」：

| 条件 | 覆盖的场景 |
|---|---|
| 前台窗口属于本进程 | `python -m app` 的 pywebview 桌面窗口 |
| 前台窗口标题以 `Miracii` 开头 | 浏览器标签页在看这个页面；心跳单独进程跑时的桌面窗口 |

第二条是标题规则，所以**跨进程也成立**：`python -m app.heartbeat` 单独跑时，主进程的窗口
同样能被认出来。代价是别的程序正好有同名前缀的窗口会误判为「人在看」——宁可少提醒，
也不要在你盯着屏幕时弹东西。

## 两层提醒

| 层 | 实现 | 说明 |
|---|---|---|
| 系统通知 | Windows PowerShell 5.1 + WinRT `ToastNotificationManager` | 默认样式（用户已确认不需要自定义配色）。AUMID 用 `Miracii`，在 `HKCU\Software\Classes\AppUserModelId\Miracii` 写一个 `DisplayName`，通知抬头显示 Miracii 而不是 Windows PowerShell；注册失败则回退到 PowerShell 的 AppID |
| 浮动弹窗（**默认关闭**） | tkinter（标准库） | 关掉的原因：它和 toast 抢右下角同一块地方，弹出来就被通知盖住，而通知本身已经够明显。代码全部保留，把 `app/notify.py` 的 `POPUP_ENABLED` 改成 `True` 即回来。行为：右下角、置顶、无边框、7 秒自动收起；**点一下把 Miracii 拉到前台**（`focus_app()` 按标题找窗口，再 `ShowWindow` + `SetForegroundWindow`）。多条同时出现时向上堆叠，最多 4 条、纵坐标下限 80px，不会算出屏幕外。配色取 `app.css` 的 `--ink/--panel/--gold/--paper` |

**没有新增依赖**：`ctypes`、`tkinter`、`subprocess` 都是标准库，`requirements.txt` 不变。
不用页面的 `Notification` API，是因为窗口最小化时页面里的东西看不见——那正是要提醒的时候。

## 开关

`persona/<id>/memory/schedule.txt`：

```text
notify: on      # 默认。off / no / false / 0 都算关
```

关掉只影响桌面提醒，`speak` 本身照常写进对话。

浮层另有一个**代码级**开关：`app/notify.py` 的 `POPUP_ENABLED`（默认 `False`）。它和 `notify:`
管的事不同——`notify: off` 把整条桌面提醒都关掉，`POPUP_ENABLED` 只管那块浮层。关掉它是有意的
取舍（和通知抢位置），不是每日偏好，所以不放进 `schedule.txt`。

## 怎么测

不必等 30 分钟，也不必真的调模型：

```powershell
# 只弹这一下，忽略焦点与开关
python -m app.notify --force "测试：她主动开口时的通知"

# 走完整链路（要 sumapi，会真的生成一句）
python -m app            # 另一个终端
python -m app.heartbeat --once idle --force-speak
```

单元测试（默认不弹任何东西，`MIRACII_NOTIFY_TEST=1` 才做真实弹窗）：

```powershell
python -m unittest discover -s tests -t .
```

## 不做的事

- 不把提醒做成独立的常驻进程或托盘图标；它跟着心跳进程活在同一个运行时里
- 不在 `notify: off` 之外再做「免打扰时段」——安静时段已经由监督那层挡住了
- 不动 `requirements.txt`，也不要求管理员权限（只写当前用户的注册表键）
