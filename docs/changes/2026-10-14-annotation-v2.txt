### B. 标注 v2（`app/warmth.py`）

标签从"一个结论"扩成"结论 + 维度辨析 + 期望路径 + 自由标签"，并且**同时记下引擎当时的判断**——
将来数据处理要比的是「引擎的判断」与「人的判断」这一对，缺一半就没法回归。

| 字段 | 取值 |
|---|---|
| `verdict` | `should_speak`（该开口）/ `should_stay_silent`（**不该此时主动对话**，含"沉默是对的"与"插得不是时候"）/ `unsure` |
| `blame`（可多选） | `connection` `pride` `hesitation` `valence` `arousal` `immersion` `user_state` `cooldown` `threshold` `timing` |
| `expected` | `none` `observation` `contact` `force_contact` `find_activity` |
| `tags` | 自由标签，便于分组（如 `深夜`、`他情绪低落`） |
| 自动记录 | 六轴、`engine_gates`、`engine_explain`、`cooldown_left`、`minutes_since_message`、`user_state` 及其判断时间 |

旧名 `ok_silent` / `na` 自动映射，老标注不失效。新增 `--stats`（汇总成人能看的一页：结论分布、
**判错的维度排行**、按结论分组的六轴均值）与 `--export`（原样导出 JSON，给数据处理用）。

## 风险与未决

- **标注 schema 还会变**：这是第二版，等人真用一阵、我们一起看数据后再定形。变更时向后兼容读（旧字段名保留识别）。
- **`--stats` 的统计口径是我定的**（按结论分组求轴均值、blame 直方图）。真正做数据处理时可能需要别的切法，
  到时候直接读 `--export` 的 JSON 自己算，不必迁就这个命令。
- `tools/review.ps1` 的 `-Protect` 默认只护 `app` 与 `tests`；要护别的目录得显式传。
- 文档里的时间线数字来自"现行默认 + 20 分钟一拍 + 距上次消息 ≥45 分钟"的干跑，**真实运行会因
  `user_state`、积压、冷却而与表略有出入**。
