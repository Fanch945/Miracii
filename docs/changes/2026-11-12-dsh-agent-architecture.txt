## 验证

```powershell
$p='docs\reference\dsh-agent-architecture.txt'
(Get-Item $p).Length                                  # 41200
(Get-Content $p -Encoding UTF8).Count                 # 563
((Get-Content $p -Encoding UTF8) | Select-String '^## ' | Measure-Object).Count   # 8（含"取证与引用约定"）
((Get-Content $p -Encoding UTF8) | Select-String '未核实' | Measure-Object).Count  # 20
((Get-Content $p -Encoding UTF8) | Select-String '已核实' | Measure-Object).Count  # 97
# 无 BOM：首字节 35 32 68（= "# D"）
```

**注意一个坑**：`Get-Content` 不加 `-Encoding UTF8` 时，本机（CP936 控制台）会把这份 UTF-8 文件
按 GBK 解码，行数被算成 **380**（把部分换行字节吞进多字节序列），小节统计也随之错。复核时务必带编码参数。
