## 3. `tick(minutesElapsed)` 完整流程（203-426）

按**源码执行顺序**编号（括号内为行号）：

1. `await ensureLoaded()`（204）。
2. `const now = new Date().toISOString()`（205）。
3. **入参校验**：`if (!minutesElapsed || minutesElapsed <= 0) return []`（207）—— `0`/负值/`NaN`/`null`/`undefined` 一律直接返回空数组，**且在 `checkThresholds()` 之前返回，因此 `lastTriggerTrace` 不被更新**。
4. `const mins = Math.min(minutesElapsed, 60)`（209）—— **单次上限 60 分钟**，无下限夹紧（非正数已在第 3 步拦掉）。
5. `stateBefore` 快照（210，仅用于日志的 5 个轴值）。
6. **Saga 偏置**：`if (opts.getSagaBias)` → `sagaBias = await opts.getSagaBias()`（215-217）；`try/catch` 空体，失败静默回退（218-220）。注释（213）声明回调返回 `{connection, pride, valence, arousal, immersion}` 每分钟偏置。
7. **昼夜偏置**：`if (opts.getCircadianBias)` → `circadianBias = await opts.getCircadianBias()`（226-228）；同样 try/catch 静默（229-231）。注释（224）声明返回 `{ arousal: 设定点偏置, arousalRegressMult: 回归速率乘数 }`。
8. **消息源**：`const lastMsg = opts.getLastMessage ? opts.getLastMessage() : null`（235，同步调用，不 await）。
9. **基础速率**：`const baseRate = opts.connectionRateFn ? opts.connectionRateFn(lastMsg) : 0.0007`（236-238）。
10. **距上次消息分钟数**：`let minutesSinceLastMsg = Infinity`（241）；`if (lastMsg && lastMsg.timestamp) minutesSinceLastMsg = (Date.now() - new Date(lastMsg.timestamp).getTime()) / 60000`（242-244）。
11. **时间分段加速**（247-251）：
    - `const accelDelay = rates.accelDelay || 0`（247）
    - `const useAccel = rates.connectionAccel > 0 && minutesSinceLastMsg >= accelDelay`（248）
    - `const accelFactor = useAccel ? Math.pow(1 + state.connection, rates.connectionAccel) : 1`（249-251）
    - 即：**`accelDelay` 之前（或 `connectionAccel<=0`）`accelFactor = 1`（纯线性）；达到 `accelDelay` 分钟后 `accelFactor = (1 + connection) ** connectionAccel`**。这里的 `state.connection` 是**本 tick 更新前**的值（因为连接更新在第 15 步）。无历史消息时 `minutesSinceLastMsg = Infinity`，`accelDelay` 默认为 0 → 立即加速。
12. **valence → connection 增长率耦合**（254-259）：
    ```
    let valenceMultiplier = 1;
    if (rates.valenceConnectDampen > 0 && state.valence < rates.valenceConnectDampenThreshold) {
      valenceMultiplier = rates.valenceConnectDampen;
    } else if (rates.valenceConnectBoost > 0 && state.valence < rates.valenceConnectBoostThreshold) {
      valenceMultiplier = rates.valenceConnectBoost;
    }
    ```
    **dampen 分支优先**：两者同时满足（例如 valence=-0.5，dampen 线 -0.4、boost 线 -0.2）时取 dampen。
13. **沉浸阻尼**（262-264）：`immersionFactor = rates.immersionDampenConnection > 0 ? 1 - state.immersion * rates.immersionDampenConnection : 1`。
14. **有效速率**（266）：`const effectiveRate = baseRate * accelFactor * valenceMultiplier * Math.max(0, immersionFactor)`（`Math.max(0,…)` 是唯一对阻尼因子的防负值处理）。
15. **connection 更新**（269-274）：
    ```
    const sagaConnectionBias = sagaBias?.connection || 0;              // 269
    state.connection = clamp(
      state.connection + (effectiveRate + sagaConnectionBias) * mins,  // 271
      axes.connection[0], axes.connection[1]);                          // 272-273
    ```
    注意：saga 偏置是**每分钟加性**叠加在 `effectiveRate` 之后（不乘任何倍率）。276-277 注释：`connectionOnReply` 自动扣除已移除，降幅由外部 LLM 分析（如 `analyzeChatSegment`）经 `applyDelta` 注入。
16. **immersion 衰减**（281-293）：
    ```
    const sagaImmersionBias = sagaBias?.immersion || 0;                                  // 281
    if (state.lastActivity) {                                                            // 282
      const sinceActivity = (Date.now() - new Date(state.lastActivity.at).getTime()) / 60000;  // 283
      const effectiveImmersionDecay = Math.max(0, rates.immersionDecay - sagaImmersionBias);   // 284
      state.immersion = Math.max(
        axes.immersion[0],
        state.immersion - effectiveImmersionDecay * Math.min(mins, sinceActivity));       // 285-288
      if (state.immersion <= 0.01 && sinceActivity > 60) {                                // 289
        state.lastActivity = null;                                                        // 290
        state.immersion = axes.immersion[0];                                              // 291
      }
    }
    ```
    要点：**没有 `lastActivity` 就完全不衰减**；衰减量取 `min(mins, sinceActivity)`；只有下限夹紧，**无上限夹紧**；`immersion<=0.01 且 sinceActivity>60` 时清空活动并把 immersion 归到轴下界。
17. **pride（防御性上升 / 回归）**（296-313）：
    ```
    const sagaPrideBias = sagaBias?.pride || 0;                                            // 296
    if (state.connection >= rates.prideDefendThreshold) {                                   // 297
      const effectiveDefendTarget = clamp(rates.prideDefendTarget + sagaPrideBias,
                                          axes.pride[0], axes.pride[1]);                    // 299
      if (state.pride < effectiveDefendTarget) {
        state.pride = Math.min(effectiveDefendTarget, state.pride + rates.prideDefendRate * mins);  // 301
      } else if (state.pride > effectiveDefendTarget) {
        state.pride = Math.max(effectiveDefendTarget, state.pride - rates.prideDefendRate * mins);  // 303
      }
    } else {
      const prideResting = clamp(sagaPrideBias, -0.3, 0.3);                                 // 307
      if (state.pride > prideResting) {
        state.pride = Math.max(prideResting, state.pride - rates.prideRegress * mins);      // 309
      } else if (state.pride < prideResting) {
        state.pride = Math.min(prideResting, state.pride + rates.prideRegress * mins);      // 311
      }
    }
    ```
    要点：防御分支的回归/上升目标是 `prideDefendTarget + saga偏置`（夹紧到轴范围），速率为 `prideDefendRate`（**双向**：高于目标也往回落）；非防御分支的静息点是 `clamp(sagaPrideBias, -0.3, 0.3)`（**硬编码 ±0.3**），速率为 `prideRegress`。两分支都不对 `state.pride` 做轴夹紧（只朝向已夹紧的目标移动）。
18. **盔甲侵蚀**（316-320）：
    ```
    if (rates.prideErosionRate > 0 &&
        state.connection >= thresholds.forceContact &&
        state.pride > 0) {

    ```
    下限是**硬编码 0**（不是 `axes.pride[0]`）。
19. **valence 回归**（323-335）：
    ```
    const valenceRegressRate = state.connection >= rates.valenceLockThreshold
      ? rates.valenceRegress * rates.valenceLockFactor
      : rates.valenceRegress;                                                                // 323-325
    const sagaValenceBias = sagaBias?.valence || 0;                                          // 328
    const effectiveValenceSetpoint = clamp(rates.valenceSetpoint + sagaValenceBias,
                                           axes.valence[0], axes.valence[1]);                // 329
    if (state.valence > effectiveValenceSetpoint) {
      state.valence = Math.max(effectiveValenceSetpoint, state.valence - valenceRegressRate * mins);  // 332
    } else if (state.valence < effectiveValenceSetpoint) {
      state.valence = Math.min(effectiveValenceSetpoint, state.valence + valenceRegressRate * mins);  // 334
    }
    ```
    锁定条件是 **connection ≥ valenceLockThreshold**（默认 1.0=永不触发），锁定时速率乘 `valenceLockFactor`。
20. **connection 驱动的 valence 下沉（改2）**（339-343）：

    ```
21. **arousal（回归力 + 上升力竞争）**（346-387）：

    const arousalSetpoint = clamp((rates.arousalSetpoint || 0) + sagaArousalBias + circadianArousalBias,
                                  axes.arousal[0], axes.arousal[1]);                          // 349

    const effectiveArousalRegress = state.valence >= rates.arousalLockThreshold
      ? baseArousalRegress * rates.arousalLockFactor
      : baseArousalRegress;                                                                   // 353-355
    let arousalRegressForce = 0;                                                              // 358
    if (state.arousal > arousalSetpoint) arousalRegressForce = -effectiveArousalRegress * mins;   // 359-360
    else if (state.arousal < arousalSetpoint) arousalRegressForce = effectiveArousalRegress * mins; // 361-362
    let arousalRiseForce = 0;                                                                 // 366
    if (state.connection >= rates.arousalConnectionRiseThreshold) {
      arousalRiseForce = rates.arousalConnectionRiseRate * mins;                              // 367-368
    }
    if (rates.prideArousalConflictRate > 0 &&
        state.connection >= thresholds.considerContact &&
        state.pride >= thresholds.prideBlock) {
      arousalRiseForce += rates.prideArousalConflictRate * mins;                              // 372-375
    }
    const netArousal = state.arousal + arousalRegressForce + arousalRiseForce;                // 379
    if (arousalRegressForce < 0 && netArousal < arousalSetpoint && arousalRiseForce === 0) {
      state.arousal = arousalSetpoint;                                                        // 381-382
    } else if (arousalRegressForce > 0 && netArousal > arousalSetpoint && arousalRiseForce === 0) {
      state.arousal = arousalSetpoint;                                                        // 383-384
    } else {
      state.arousal = clamp(netArousal, axes.arousal[0], axes.arousal[1]);                    // 386
    }
    ```
    要点：锁定条件是 **valence ≥ arousalLockThreshold**（与 valence 锁定的条件轴相反）；`arousalRiseForce === 0` 是严格相等判定（注释 380「回归力不会推过设定点（除非上升力在反方向拉）」）。
22. `state.lastTick = now`（389）。
23. `const triggers = checkThresholds()`（392）—— 顺带把 `lastTriggerTrace` 更新（见第 4 节）。
24. **日志**（395-422）：`verbose` 时每次 tick 打印（396-405），并在 `triggers.length === 0` 时追加 `[积温] 未触发原因: ${explainTrigger()}`（407-409）；非 verbose 时仅在 `triggers.length > 0` 打印（410-421）。日志字段：`tick {mins}min | c/p/v/a/i 前后值 | 速率:{effectiveRate.toFixed(4)}/min | 触发: …`。
25. `await save()`（424）。
26. `return triggers`（425）—— 触发对象数组（第 4 节）。

## 4. 触发判定 `checkThresholds()`（429-533）

返回值：`triggers` 数组；副作用：`lastTriggerTrace = trace`（531）。
局部量（434-439）：`c/p/i/v/a` 分别是 connection/pride/immersion/valence/arousal 的当前值；`const r3 = (n) => Number(n.toFixed(3))`（439，仅用于 trace 的 detail）。

闸门按源码顺序（每个 `if` 独立求值，**不是 else-if 链**，除了第 1 组内部的 else-if）：

### 4.1 开口区 · observation（441-458）

```
if (c >= thresholds.observation && c < thresholds.considerContact) {          // 441
  triggers.push({
    action: 'observation',
    urgency: (c - thresholds.observation) /
             (thresholds.considerContact - thresholds.observation),           // 444-445
  });
  trace.push({ gate: '开口', fired: true, action: 'observation',
    reason: 'connection 进了观察区',
    detail: { connection: r3(c), 观察线: thresholds.observation, 考虑线: thresholds.considerContact } });  // 447-451
} else if (c < thresholds.observation) {                                      // 452
  trace.push({ gate: '开口', fired: false, reason: 'connection 还没到观察线',
    detail: { connection: r3(c), 还差: r3(thresholds.observation - c) } });   // 453-457
}
```
- 返回字段：**仅 `action` + `urgency`**（`urgency` 已归一化到 `[0,1)`，无夹紧但仍等价于比例）。
- `c ≥ forceContact` 时本组**两条分支都不进**（452 的 else-if 只捕获 `c < observation`），因此该情况下的「开口」闸门记录只来自 4.3。
- 消费方如需 `connection` 阈值信息，只能从 `detail` 取。

### 4.2 考虑区 · contact / find_activity（460-491）

```
if (c >= thresholds.considerContact && c < thresholds.forceContact) {         // 460
  if (p >= thresholds.prideBlock) {                                           // 461
    if (i < 0.2) {                                                            // 462  ← 硬编码 0.2
      triggers.push({ action: 'find_activity', reason: 'pride_block',
                      urgency: c - 0.30 });                                   // 463-467  ← 硬编码 0.30
      trace.push({ gate: '开口', fired: false, divertedTo: 'find_activity',
        reason: 'pride 挡住开口，转身去找事做',
        detail: { pride: r3(p), 嘴硬线: thresholds.prideBlock, immersion: r3(i) } });   // 468-472
    } else {
      trace.push({ gate: '开口', fired: false,
        reason: 'pride 挡住开口，immersion 又缓冲住了（没转成找事做）',
        detail: { pride: r3(p), 嘴硬线: thresholds.prideBlock, immersion: r3(i), immersion上限: 0.2 } }); // 474-478
    }
  } else {
    triggers.push({ action: 'contact', urgency: c - 0.30 });                  // 481-484 ← 硬编码 0.30
    trace.push({ gate: '开口', fired: true, action: 'contact',
      reason: '过了 pride 闸门',
      detail: { pride: r3(p), 嘴硬线: thresholds.prideBlock } });              // 485-489
  }
}
```
- `prideBlock` 闸门：`p >= thresholds.prideBlock` **直接吞掉开口**，不产生 `contact`。
- `immersion` 缓冲：被 pride 挡住后，`i < 0.2` 才转成 `find_activity(reason:'pride_block')`；`i >= 0.2` 时**什么触发都不产生**，只留一条 `fired:false` 轨迹。
- `urgency` 值用**硬编码 0.30**（不是 `thresholds.considerContact`）。

### 4.3 强制区 · forced contact（493-504）

```
if (c >= thresholds.forceContact) {                                          // 493
  triggers.push({ action: 'contact', urgency: Math.min(1, c - 0.40), forced: true });  // 494-498 ← 硬编码 0.40
  trace.push({ gate: '开口', fired: true, action: 'contact', forced: true,
    reason: '过了强制线，pride 挡不住了',
    detail: { connection: r3(c), 强制线: thresholds.forceContact } });        // 499-503
}
```
- **`forced: true` 只在这里出现**，且**完全无视 pride 与 immersion**。`urgency` 夹紧到 `[.., 1]`（无下限夹紧）。

### 4.4 低情绪自我调节 · find_activity（507-529）

```
if (v <= thresholds.valenceActivity || a >= thresholds.arousalAgitation) {    // 507
  const alreadyFinding = triggers.some(t => t.action === 'find_activity');    // 508
  const lowValence = v <= thresholds.valenceActivity;                         // 509
  if (!alreadyFinding && i < 0.3) {                                           // 510  ← 硬编码 0.3
    const reason = lowValence ? 'low_valence' : 'high_arousal';               // 511
    triggers.push({ action: 'find_activity', reason,
                    urgency: Math.min(1, Math.abs(lowValence ? v : a) / 1) });// 512-516
    trace.push({ gate: '自我调节', fired: true, action: 'find_activity',
      reason: lowValence ? 'valence 过低' : 'arousal 过高',
      detail: { valence: r3(v), arousal: r3(a) } });                          // 517-521
  } else if (!alreadyFinding) {
    trace.push({ gate: '自我调节', fired: false,
      reason: 'immersion 太高，没转去找事做',
      detail: { immersion: r3(i), immersion上限: 0.3 } });                     // 523-527
  }
}
```
- 触发条件：`valence <= valenceActivity` **或** `arousal >= arousalAgitation`。
- 去重：若前面（4.2 的 `pride_block`）已产生 `find_activity`，则**本组不再产生触发、也不写轨迹**（`alreadyFinding` 为真时两个分支都不进）。
- `immersion` 缓冲线硬编码 `0.3`；`reason` 在两条件同时成立时取 `'low_valence'`（509/511）。`urgency = min(1, |值| / 1)`（除 1 是恒等，无实际作用）。

### 4.5 触发总数与组合（推论自上述结构）

- 开口类（observation | contact | find_activity(pride_block) 或「什么也不发生」）三选一（区间互斥）。
- 自我调节类最多再补一个 `find_activity`。
- 因此 `triggers.length ∈ {0, 1, 2}`；`trace.length ≤ 2`。
- trace 的 `gate` 取值只有 `'开口'`（447/453/468/474/485/499）与 `'自我调节'`（517/523 共两处分支）。
- **动作名与字段总表**：

| action | 出现位置 | 携带字段 |
|---|---|---|
| `observation` | 441-446 | `action`, `urgency`（比例，无 `reason`、无 `forced`） |
| `contact` | 480-484 | `action`, `urgency = c-0.30` |
| `contact` | 493-498 | `action`, `urgency = min(1, c-0.40)`, **`forced: true`** |

### 4.6 `getTriggerTrace()`（538-540）

返回 `lastTriggerTrace`（**同一数组引用，不拷贝**）。元素形状：

### 4.7 `explainTrigger()`（543-551）

```
if (lastTriggerTrace.length === 0) return '（还没 tick 过）';                 // 544
const fired = lastTriggerTrace.filter(t => t.fired);                          // 545
const blocked = lastTriggerTrace.filter(t => !t.fired);                       // 546
if (fired.length > 0) {
  return '已触发: ' + fired.map(t => t.action + '（' + t.reason + '）').join('、');  // 548
}
return '未触发: ' + blocked.map(t => t.reason).join('；');                     // 550
```

### 5.1 `applyDelta(delta)`（576-633）逐步

1. `await ensureLoaded()`（577）；`const scaled = { ...delta }`（579，浅拷贝，不修改调用方对象）。
2. **改3 边际递减**（582-600），条件 `scaled.valence !== undefined && rates.valenceDiminishWindow > 0 && rates.valenceDiminishFactor > 0`：
   - `windowMs = rates.valenceDiminishWindow * 60 * 1000`（585）
   - 倒序清理 `_valenceDeltaLog` 中 `now - time > windowMs` 的项（587-589）
   - `sameSign = _valenceDeltaLog.filter(d => (scaled.valence > 0 && d.value > 0) || (scaled.valence < 0 && d.value < 0))`（591-593）
   - `cumSum = sameSign.reduce((s, d) => s + Math.abs(d.value), 0)`（594）
   - `if (cumSum > 0) { const scale = 1 / (1 + cumSum * rates.valenceDiminishFactor); scaled.valence *= scale; }`（595-598）
   - `_valenceDeltaLog.push({ time: now, value: delta.valence })`（599）——**记原始值**（注意用 `delta.valence` 而非 `scaled.valence`）。
3. **改1 valence 状态相关缩放**（603-611），条件 `scaled.valence !== undefined && rates.valenceDeltaScaling`：
   - `if (scaled.valence > 0 && state.valence > 0.3) { const dampen = (state.valence - 0.3) / 0.7 * 0.5; scaled.valence *= (1 - dampen); }`（604-606，注释 0.3→0%, 1.0→50%）
   - `else if (scaled.valence < 0 && state.valence < -0.3) { const dampen = (-state.valence - 0.3) / 0.7 * 0.5; scaled.valence *= (1 - dampen); }`（607-610）
4. **arousal 缩放**（615-618），条件 `scaled.arousal > 0 && state.arousal > 0.4 && rates.arousalDeltaScaling`：
   `const dampen = (state.arousal - 0.4) / 0.6 * 0.5; scaled.arousal *= (1 - dampen);`（0.4→0%, 1.0→50%）
5. **逐轴写入（顺序固定）**，每个都夹紧到对应轴范围：
   - `if (scaled.pride !== undefined) state.pride = clamp(state.pride + scaled.pride, axes.pride[0], axes.pride[1])`（620-621）
   - `if (scaled.valence !== undefined) state.valence = clamp(state.valence + scaled.valence, axes.valence[0], axes.valence[1])`（622-623）
   - `if (scaled.arousal !== undefined) state.arousal = clamp(state.arousal + scaled.arousal, axes.arousal[0], axes.arousal[1])`（624-625）
   - `if (scaled.connection !== undefined) state.connection = clamp(state.connection + scaled.connection, axes.connection[0], axes.connection[1])`（626-627）
   - **向后兼容 `mood`**：`if (scaled.mood !== undefined) state.valence = clamp(state.valence + scaled.mood, axes.valence[0], axes.valence[1])`（629-631）——在 valence 之后**再叠加一次**。
6. `await save()`（632）。
7. **`applyDelta` 不校验数值量级、不校验类型**：没有任何 `isNaN` / `Number.isFinite` / 幅度上限；唯一的「夹紧」是写入时的轴范围 clamp。

### 6.2 查表与回退

```
function getUnifiedGuidance(state, mode) {                                    // 209
  const { connection: c, pride: p, valence: v, arousal: a } = state;          // 210
  const cluster = classifyCluster(v, a);                                      // 212
  const prideTier = classifyPride(p);                                         // 213
  const urgencyLevel = classifyUrgency(c);                                    // 214
  const lines = [];                                                           // 216
  const profile = profiles[cluster] || profiles.neutral;                      // 217  ← 缺簇回退 neutral
  const coreLines = profile[prideTier] || profile[3];                         // 218  ← 缺档回退 tier 3
  lines.push(...coreLines);                                                   // 219
  const urgencyLine = urgency[urgencyLevel]?.[mode];                          // 221
  if (urgencyLine) lines.push(urgencyLine);                                   // 222
  if (lines.length === 0) return '';                                          // 224
  return lines.join('\n');                                                    // 225
}
```

- **缺格回退规则**：簇缺失 → `profiles.neutral`（217）；档位缺失 → `profile[3]`（218）；`urgency` 缺失/为 `null` → 静默跳过（221-222 的可选链 + 真值判断）；全部为空 → 返回 `''`（224-225）。
- **回退的边界坑**：若 `profile[3]` 也缺失，`coreLines` 为 `undefined`，219 行的 `lines.push(...undefined)` 会抛 `TypeError`（默认 9 簇都填了 tier 3，故默认配置不触发）。

### 6.3 分类函数（判定顺序即优先级）

- `classifyCluster(v, a)`（162-172）：
  ```
  v > 0.3 && a > 0.3   → 'excited'    (163)
  v > 0.3 && a < -0.3  → 'content'    (164)
  v > 0.3              → 'pleased'    (165)
  v < -0.3 && a > 0.3  → 'agitated'   (166)
  v < -0.3 && a < -0.3 → 'depressed'  (167)
  v < -0.3             → 'sullen'     (168)
  a > 0.3              → 'restless'   (169)
  a < -0.3             → 'calm'       (170)
  否则                  → 'neutral'    (171)
  ```
  边界值 `±0.3` 严格比较（`>`/`<`），恰好 0.3 落到后面的分支。
- `classifyPride(p)`（175-181）：`>0.8→5`、`>0.5→4`、`>0.3→3`、`>0.1→2`、`else 1`。
- `classifyUrgency(c)`（184-189）：`>=0.50→'desperate'`、`>=0.35→'urgent'`、`>=0.20→'aware'`、`else 'none'`。**这组阈值与 `thresholds` 无关，是硬编码**（默认阈值的 observation/considerContact/forceContact 恰好是 0.20/0.35/0.50）。

### 6.4 工厂与导出

- `createToneGrid(opts = {})`（199-241）：`opts.profiles`（200-202）、`opts.urgencyBoost`（204-206）。
- 返回：`getUnifiedGuidance(state, mode)`（230）、`getStyleGuidance: (state) => getUnifiedGuidance(state, 'reactive')`（233）、`getPromptContext: (state) => getUnifiedGuidance(state, 'proactive')`（236）、`config: { profiles, urgency }`（239）。
- 导出：`module.exports = { createToneGrid, DEFAULT_PROFILES, DEFAULT_URGENCY }`（243）。
- 接入 jiwen 的方式：作为 `opts.getStyleGuidance` / `opts.getPromptContext` 注入（tone-grid.js:16-20 注释、README.md:318-322）。`tone-grid.js` **没有任何测试覆盖**（`jiwen.test.js:6-7` 只 require `./jiwen` 与 `./simulate`）。

### 7.4 其他坑

- **无 NaN / 非有限值防护**：`jiwen.js` 全文没有 `isNaN` / `Number.isNaN` / `Number.isFinite` / `isFinite`（grep 0 命中；`Number.isFinite` 只出现在 `jiwen.test.js:208-209` 的断言里）。`clamp` 对 `NaN` 返回 `NaN`（`Math.min(max, NaN) → NaN`，`Math.max(min, NaN) → NaN`），因此 `applyDelta({valence: NaN})` 会把该轴永久污染成 `NaN`；`Infinity` 会被 clamp 夹住。
- **`-0` 字面量**：`axes.connection = [-0, 1]`（31），`DEFAULT_STATE.connection`（151）与 `resetConnection` 结果（644）都是 `-0`；JS 中 `-0 === 0` 为真、`JSON.stringify(-0)` 为 `"0"`（测试 `jiwen.test.js:128` 用 `after === 0` 断言通过）。
- **默认初值是各轴下界**（151-155），不是 0；`getState()` 冷启动返回 `{connection:-0, pride:-1, valence:-1, arousal:-1, immersion:0}`。
- **`opts.initialState` 未实现**（仅 JSDoc:14；CLAUDE.md:58 明确说明）；初始状态只能由 `onLoad` 提供，且 `load()` 用浅合并（180）——`onLoad` 返回的对象里**缺失的键会保留 DEFAULT_STATE 的下界值**。
- **无效键静默忽略**：`connectionGrowth`（40）与 `connectionOnReply`（41）声明后无任何读取点，设置它们不产生效果。
- **`getLastMessage` / `connectionRateFn` 是同步调用**（235-237），返回值不会被 await；若传入 async 函数，`lastMsg` 会是 Promise，`lastMsg.timestamp` 为 `undefined` → `minutesSinceLastMsg` 保持 `Infinity`。
- **`tick` 早退不更新轨迹**（207 在 392 之前）。
- **每轴更新顺序固定**：connection → immersion → pride（防御/回归）→ pride（侵蚀）→ valence（回归）→ valence（下沉）→ arousal（346-387）。同一 tick 内后面的轴能看到前面轴的新值（如 pride 防御用更新后的 connection；arousal 锁定用更新后的 valence）。
- **`checkThresholds` 是公开方法**（729），外部调用会覆写 `lastTriggerTrace`；它同步执行、不 save。
- **`getState()` 是浅拷贝**（638），`lastActivity` 对象可被外部改到内部状态。
- **`config` 未冻结**（740-746），`config.rates.prideDefendRate = 1` 之类会直接改到运行时参数（闭包引用的是同一个对象）。
- **`_valenceDeltaLog` 不持久化**（172 注释「闭包内，不持久化」），进程重启即清空；只有 `valenceDiminishWindow>0 && valenceDiminishFactor>0` 时才写入。
- **`save()` 无节流**：`tick`/`applyDelta`/`setActivity`/`resetConnection`/所有 setter 各调用一次。
- **日志默认会输出到 stdout**：未提供 `onLog` 时，阈值触发那几次 tick 一律 `console.log`（144-146、410-421）。
